Whether outbound connections are routed through fault-injecting proxies. Decided at build time: when off, the extension registers no interceptor and no proxy. Exhausting a pool or the worker pool and watching the event loops need no flag: they work on the application itself, not on its connections.

Off by default. Test classes opt in with `@TestProfile(NetworkFaultsProfile.class)`, whose config overrides set this to `true` for the build made for that profile.
